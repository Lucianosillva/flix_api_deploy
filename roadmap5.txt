Permissões de usuários - Criando classe de permissão...

As permissões no django são implementadas no código e depois gerenciadas no admin, e baseadas em métodos (crud) (e em cada model) em cada usuário comum (o super pode fazer tudo e não precisa explicitar) existente no admin.

Um exemplo seria um user que só visualiza, (ou utiliza só os safe methods que são get, option, head, ou seja, só consume dados, não altera...) outro que visualiza e altera (exceto tabelas do sistema) que seria um admin, e não um superuser...

Criando classe global de permissões


vamos criar uma classe global de permissões que será usada no projeto inteiro, em todos os apps e models...
a lógica será a mesma que foi criada em genres, porém será genérico, ou seja, pode ser usada em todos os apps...

o permissions de genres pode comentar ou deletar que não vamos mais usar ele...


dentro de app crie permissions.py...

que tera...



from rest_framework import permissions


class GlobalDefaultPermission(permissions.BasePermission):
    
    # função principal...
    def has_permission(self, request, view):
        model_permission_codename = self.__get_model_permission_codename(
            method=request.method,
            view=view,
        )
        
        if not model_permission_codename:
            return False
        
        return request.user.has_perm(model_permission_codename)
    
    # para montar a string, tipo (genres.view_genre) (app_name.ação_model_name)
    def __get_model_permission_codename(self, method, view):
        try:
            app_label = view.queryset.model._meta.app_label
            action = self.__get_action_sufix(method)
            model_name = view.queryset.model._meta.model_name
            return f'{app_label}.{action}_{model_name}'
            
        except AttributeError:
            return None
    
    # saber qual método está chegando...
    def __get_action_sufix(self, method):
        method_actions = {
            'GET': 'view',
            'OPTIONS': 'view',
            'HEAD': 'view', 
            'POST': 'add',
            'PUT': 'change',
            'PATCH': 'change',
            'DELETE': 'delete',
            
        }
        return method_actions.get(method, '')
