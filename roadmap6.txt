 class MovieStatsView(views.APIView):
    permission_classes = (IsAuthenticated, GlobalDefaultPermission)
    queryset = Movie.objects.all()
    # não precisa de serializer pq os dados já vão ser serializados manualmente...
    
    
    def get(self, request):
        total_movies = self.queryset.count()
        # values, retorna o nome do gênero
        # annotate, retorna uma query com algum dado extra
        movies_by_genre = self.queryset.values('genre__name').annotate(count=Count('id'))
        total_reviews = Review.objects.count()
        average_stars = Review.objects.aggregate(avg_stars=Avg('stars'))['avg_stars']
        
        return response.Response(data=
            {'total_movies': total_movies,
             'movies_by_genre': movies_by_genre,
             'total_reviews': total_reviews,
             'average_stars': round(average_stars, 1) if average_stars else 0,
            }, status=status.HTTP_200_OK,
            
        )

Backend For Frontend e Api Gateway


Numa API RestFul os dados serializados são devolvidos de forma crua, ou seja, listando filmes retornaria os nomes deles, e retorna os ids dos atores ao invés de retornar o nome, depois para saber teria que fazer outro get em atores, para tratar isso e deixar as respostas mais amigáveis para os usuários (Frontend) existe o Api Gateway. Mas para implementar um Api Gateway precisa montar uma grande estrutura e a maioria não usam isso, e ao ínves disso, na vida real, esse tratamento é montado na própria api.

Como exemplo vamos montar no app movies uma estrutura que mostra por exemplo uma lista de atores ao invés de ids, e fazendo isso a api vai sair um pouco do padrão RestFul, mas na prática é assim mesmo...

Django command

São comandos que chamamos no terminal do django que servem para rodar algum script, rodar alguma automação, etc (exemplos: python manage.py runserver, python manage.py migrate, etc).

Podemos também criar nossos próprios comandos personalizados de acordo com as necessidades do nosso projeto e que roda no contexto do nosso projeto, por exemplo, podemos criar um comand que importa e insere no banco de dados uma lista de atores que está salva num arquivo csv ou excel, sem precisar cadastrar cada item desta lista um a um...


********** E como criar um Django command?

antes de criar na prática vamos criar uma estrutura que serve de base...

no app de actors crie...

mkdir actors/management/commands

dentro de management e de commands crie um arquivo __init__py em cada...

dentro de commands crie um arquivo import_actors.py e nele crie o django command de fato...

que fica assim...



from django.core.management.base import BaseCommand


class Command(BaseCommand):
    
    def add_arguments(self, parser):
        parser.add_argument(
            'file_name',
            type=str,
            help='Nome do arquivo com atores.'
        )
    
    def handle(self, *args, **options):
        file_name = options['file_name']
        
        print(f'MEU PRIMEIRO COMMAND: file_name: {file_name}')

atualize o arquivo import_actors para...




import csv
from datetime import datetime
from django.core.management.base import BaseCommand
from actors.models import Actor


class Command(BaseCommand):
    
    def add_arguments(self, parser):
        parser.add_argument(
            'file_name',
            type=str,
            help='Nome do arquivo CSV com atores.'
        )
    
    def handle(self, *args, **options):
        # pega o argumento de add_argument...
        file_name = options['file_name']
        
        # abrindo e lendo linha a linha o arquivo (actors.csv) passado como argumento...
        with open(file_name, 'r', encoding='utf-8') as file:
            reader = csv.DictReader(file)
            for row in reader:
                name = row['name']
                birthday = datetime.strptime(row['birthday'], '%Y-%m-%d').date()
                nationality = row['nationality']
                
                # informa cada linha sendo add...
                self.stdout.write(self.style.NOTICE(name))
                
                Actor.objects.create(
                    name = name,
                    birthday = birthday,
                    nationality = nationality
                )
        
        # informa que finalizou o import...      
        self.stdout.write(self.style.SUCCESS('Atores importados com sucesso!'))


e para rodar...

python manage.py import_actors actors.csv
